## How a token gets from Figma to code

1. `scripts/export-figma-variables.js` runs inside the Figma file and writes every local variable, its modes and its aliases to `tokens/figma-variables.json`.
2. `npm run tokens` turns that file into `src/tokens/tokens.css` (CSS variables) and `src/tokens/tokens.ts` (the same data for TypeScript).
3. `npm run check:tokens` loads the CSS in a browser and confirms every variable, in every mode, resolves to the value Figma has.
4. These pages read `tokens.ts` and render with the CSS variables, so a page is wrong only if the tokens are wrong.

The JSON file is the snapshot of record. Change a value in Figma, export again, rebuild. Don't edit the generated files.
